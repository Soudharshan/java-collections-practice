# Java Collections Practice

Solutions to 20+ coding problems using ArrayList, HashSet, HashMap, Stack.

## Problems

### ArrayList
1. Remove Consecutive Duplicates – O(n) time, O(n) space  
   Input: [1,1,2,2,2,3,1,1,4] → Output: [1,2,3,1,4]
2. Rotate ArrayList by K – O(n) time, O(1) space  
   Input: [1,2,3,4,5], k=2 → Output: [4,5,1,2,3]
3. Leaders in Array – O(n) time, O(n) space  
   Input: [16,17,4,3,5,2] → Output: [17,5,2]
4. Move Zeros to End – O(n) time, O(1) space  
   Input: [0,1,0,3,12] → Output: [1,3,12,0,0]
5. Find Pair with Target Sum – O(n) time, O(n) space  
   Input: [2,7,11,15], target=9 → Output: true

### HashSet
6. Longest Consecutive Sequence – O(n) time, O(n) space  
   Input: [100,4,200,1,3,2] → Output: 4
7. First Repeated Element – O(n) time, O(n) space  
   Input: [2,5,1,2,3,5] → Output: 2
8. Happy Number – O(log n) time, O(log n) space  
9. Common Unique Elements – O(n+m) time  
10. Missing Positive Integer – O(n) time, O(n) space

### HashMap
11. Two Sum – O(n) time, O(n) space  
12. Group Anagrams – O(n * k log k) time  
13. Character Frequency Sort – O(n log n) time  
14. Top K Frequent Elements – O(n log k) time  
15. Find Duplicate File Names – O(n) time

### Stack
16. Valid Parentheses – O(n) time, O(n) space  
17. Next Greater Element – O(n) time, O(n) space  
18. Remove Adjacent Duplicates – O(n) time, O(n) space  
19. Decode String – O(n) time, O(n) space  
20. Stock Span – O(n) time, O(n) space

### Extra Problems
- Product of Array Except Self – O(n) time, O(1) space  
- Majority Element (Boyer-Moore) – O(n) time, O(1) space  
- Find All Pairs with Given Sum – O(n) time, O(n) space  
- Merge Two Sorted Arrays Without Extra Space – O((n+m) log(n+m)) time
