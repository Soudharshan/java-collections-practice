# Java Collections Practice

Solutions to 20+ coding problems using ArrayList, HashSet, HashMap, and Stack.

## Problems

### ArrayList
1. Remove Consecutive Duplicates – O(n) time  
2. Rotate ArrayList by K – O(n) time  
3. Leaders in Array – O(n) time  
4. Move Zeros to End – O(n) time  
5. Find Pair with Target Sum – O(n) time  
- Extra: Product of Array Except Self  
- Extra: Majority Element (Boyer-Moore)  
- Extra: Find All Pairs with Given Sum  
- Extra: Merge Two Sorted Arrays (no extra space)

### HashSet
6. Longest Consecutive Sequence – O(n) time  
7. First Repeated Element – O(n) time  
8. Happy Number – O(log n) time  
9. Common Unique Elements – O(n+m) time  
10. Missing Positive Integer – O(n) time

### HashMap
11. Two Sum – O(n) time  
12. Group Anagrams – O(n * k log k) time  
13. Character Frequency Sort – O(n log n) time  
14. Top K Frequent Elements – O(n log k) time  
15. Find Duplicate File Names – O(n) time

### Stack
16. Valid Parentheses – O(n) time  
17. Next Greater Element – O(n) time  
18. Remove Adjacent Duplicates – O(n) time  
19. Decode String – O(n) time  
20. Stock Span – O(n) time

## How to Run (locally)
```bash
javac src/com/practice/**/*.java
java src.com.practice.Main
```
